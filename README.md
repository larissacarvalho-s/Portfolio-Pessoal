# Portfólio — Larissa Carvalho Silva

## Sobre o projeto

Este é meu portfólio acadêmico, desenvolvido para apresentar meu perfil, minha formação, minhas habilidades e projetos realizados durante meus estudos na área de tecnologia.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript

## Funcionalidades

- Menu de navegação responsivo com links para as seções da página.
- Seções de perfil, formação e habilidades, projetos e contato.
- Cards para apresentação dos projetos.
- Layout adaptável para computadores e dispositivos móveis.

## Recurso novo e implementação

Além das seções obrigatórias, foi criada uma seção de **Formação e habilidades** para apresentar os cursos e conhecimentos estudados. Também foram adicionados efeitos de hover e transições nos cards de formação, projetos e links de contato. Esses efeitos foram implementados com CSS usando `transition` e `:hover`, proporcionando retorno visual ao passar o cursor pelos elementos.
